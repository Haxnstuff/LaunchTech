# LaunchTech

A dark, cyberpunk-styled launcher for your Windows games and apps. Point it at the folders your games live in, and it finds them, pulls in their icons, and keeps the list up to date.

LaunchTech only reads your game folders. It never changes them.

## Download

Get the latest version from [Releases](../../releases/latest). Pick one:

- **LaunchTech-…-Portable.exe** runs straight away with nothing to install.
- **LaunchTech-….msi** installs LaunchTech with desktop and Start menu shortcuts.

LaunchTech isn't code-signed, so Windows may say "Windows protected your PC". Click **More info**, then **Run anyway**.

Requires 64-bit Windows 10 or 11.

## Setup

1. Open LaunchTech.
2. Click **Add folder**.
3. Choose the folder that holds your games, for example `D:\SteamLibrary\steamapps\common`. Each folder inside it becomes a game in your library.
4. To add more folders later, go to **Settings → Discovery → Add folder**.

New games you install into those folders show up on their own.

If a game is missing, open **Settings → Discovery → Skipped**, find its folder, and click **Pick file** to choose the `.exe` that starts it.
